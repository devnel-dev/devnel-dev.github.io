집밥노트 개인정보처리방침

시행일: 2026년 9월 22일

Devnel(이하 “운영자”)은 Android 앱 집밥노트를 이용하는 과정에서 처리되는 개인정보와 이용자 데이터의 처리 방법을 다음과 같이 안내합니다.

1. 처리하는 정보와 이용 목적

집밥노트의 레시피, 식단, 냉장고 재료, 태그, 앱 설정 등 대부분의 데이터는 이용자의 기기에 저장됩니다. 운영자는 자체 회원 서버나 자체 분석 서버를 운영하지 않습니다.

집밥노트는 기능 제공을 위해 다음 정보를 처리할 수 있습니다.

  • 레시피·식단·냉장고·태그 정보: 요리명, 재료, 메모, 태그, 링크, 사진, 식단 정보, 냉장고 재료 및 기한 등. 레시피·식단·재료 관리 기능 제공을 위해 기기에 저장됩니다.
  • Google 계정 연결 정보: Google 계정 식별정보와 이메일 주소. Google Drive 백업·복원 기능의 계정 확인과 인증을 위해 사용됩니다.
  • Google Drive 백업 데이터: 저장된 레시피와 사진, 식단, 냉장고 재료, 태그 및 백업에 필요한 부가정보. 이용자가 Google Drive 백업 기능을 사용하는 경우 연결한 Google 계정의 앱 전용 저장공간에 저장됩니다.
  • 광고 관련 정보: Google Mobile Ads SDK가 광고 제공, 측정, 보안 및 부정 이용 방지를 위해 IP 주소, IP 주소를 통해 추정되는 대략적인 위치, 광고·앱 상호작용 정보, 진단정보, 광고 ID 또는 앱 세트 ID 등 기기 식별정보를 처리할 수 있습니다.
  • 사진 글자 인식 관련 정보: 냉장고 재료 사진 인식 기능은 Google ML Kit를 사용합니다. 선택한 사진과 인식 결과는 글자 인식 목적으로 기기에서 처리되며, ML Kit는 별도로 앱·기기 정보와 기능 이용·성능·오류 관련 진단정보를 Google에 전송할 수 있습니다.
  • 손글씨 사진 간편 입력: 이용자가 선택한 사진을 Gemini 또는 이용자가 직접 선택한 외부 앱으로 공유할 수 있으며, 입력을 돕기 위한 안내문을 클립보드에 복사합니다. 외부 앱으로 공유된 사진과 입력 내용은 해당 서비스의 개인정보처리방침에 따라 처리됩니다.
  • 유튜브 레시피 간편 정리: 유튜브 링크가 포함된 안내문을 클립보드에 복사하고 Chrome 브라우저에서 Gemini 웹페이지를 엽니다. 실제 제출은 이용자가 외부 서비스에서 직접 수행합니다.
  • YouTube 삽입 플레이어: 레시피에 저장된 YouTube 영상을 앱 안에서 재생하는 경우 YouTube의 콘텐츠와 관련 자원이 로드되며, Google/YouTube가 접속·기기·이용 관련 정보를 처리할 수 있습니다.
  • 공지사항: 공지사항 화면을 열면 GitHub Pages에 게시된 공지 데이터를 HTTPS로 불러옵니다. 이 요청에 레시피, 식단, 냉장고 내용이나 연결한 Google 계정 정보는 포함하지 않습니다. 다만 GitHub는 서비스 운영 및 보안을 위해 IP 주소 등 접속정보를 처리할 수 있습니다.
  • 이메일 문의: 이용자가 문의 이메일을 보내는 경우 발신 이메일 주소, 표시 이름, 문의 내용과 이용자가 직접 첨부한 파일을 문의 확인과 답변을 위해 처리합니다.

레시피 메모나 사진 등에 이용자가 직접 개인정보를 입력한 경우 해당 정보도 기기에 저장되거나, 이용자가 선택한 백업·공유 기능을 통해 외부 서비스에 전달될 수 있습니다.

2. 개인정보 및 이용자 데이터의 보유 기간

기기 내 데이터

레시피, 식단, 냉장고 재료, 태그 등은 이용자가 삭제하거나 Android의 앱 저장공간 데이터를 삭제할 때까지 기기에 보관됩니다.

작성 중인 초안과 앱 설정, 계정 연결 상태, 백업 작업 상태, 광고 제거 혜택 관련 기록 등은 각 기능의 동작을 위해 별도로 기기에 저장될 수 있습니다.

Google Drive 백업

Google Drive 백업은 직접 백업과 자동 백업을 구분하여 각각 최근 2개의 백업본을 유지하도록 정리합니다. 통신 또는 삭제 오류가 발생한 경우 일시적으로 더 많은 백업본이 남을 수 있습니다.

자동 백업을 끄거나 Google 계정 연결을 해제하거나 앱을 삭제해도 이미 Google Drive에 저장된 백업본이 자동으로 삭제되는 것은 아닙니다. 이용자는 앱의 보관 중인 백업본 모두 삭제 기능을 이용하여 집밥노트가 인식하는 백업본을 삭제할 수 있습니다.

문의 이메일 및 첨부파일

문의 이메일은 접수일로부터 1년간 보관합니다. 다만 문의 처리 또는 분쟁 대응이 계속되는 경우에는 해당 목적이 달성될 때까지 보관하며, 이후 지체 없이 삭제합니다.

문의용 이메일 계정은 운영자만 접근하며 2단계 인증을 사용합니다. 문의 처리에 필요한 경우 이용자가 첨부한 파일을 운영자의 PC에 저장할 수 있으며, 처리에 필요하지 않은 경우 별도로 저장하지 않습니다. PC에 저장한 첨부파일도 해당 문의의 보관기간을 넘기지 않고 삭제합니다.

3. Google Drive 백업·복원

Google 계정을 연결하면 집밥노트는 이용자가 허용한 권한을 이용하여 해당 계정의 Google Drive 앱 전용 숨김 저장공간(appDataFolder)에 집밥노트 백업 파일을 저장하고, 백업 목록 조회·다운로드·복원·삭제 기능을 제공합니다.

집밥노트는 이용자의 일반 Google Drive 문서 전체를 조회하기 위한 권한을 사용하지 않으며, 운영자의 자체 서버에 백업 파일을 복제하지 않습니다. 운영자가 이용자의 개인 Google Drive 백업을 열람하는 별도 관리 기능도 제공하지 않습니다.

자동 백업은 이용자가 기능을 켠 경우 Android가 비과금 네트워크(unmetered)로 판단하는 연결 등 시스템 작업 조건에 따라 백그라운드에서 실행될 수 있습니다.

백업 ZIP에는 별도 비밀번호나 종단간 암호화를 적용하지 않습니다. Google Drive의 저장 및 보호 방식에는 Google의 정책이 적용됩니다.

4. 광고 및 외부 서비스

Google AdMob 및 UMP

집밥노트는 Google Mobile Ads SDK를 이용해 배너 광고와 이용자가 선택하는 보상형 광고를 제공합니다. 광고 제공 방식과 개인정보 처리 범위는 이용자의 지역, Google의 광고 설정, 동의 상태 및 서비스 정책에 따라 달라질 수 있습니다.

앱은 Google의 User Messaging Platform(UMP)을 통해 필요한 경우 개인정보 관련 동의 상태를 확인하고 관련 메시지를 표시할 수 있습니다.

  • Google 개인정보처리방침: https://policies.google.com/privacy?hl=ko
  • Google Mobile Ads 데이터 공개 안내: https://developers.google.com/admob/android/privacy/play-data-disclosure

Google ML Kit

냉장고 사진 글자 인식은 Google ML Kit를 이용합니다. 사진 내용과 글자 인식 결과는 인식 기능을 위해 기기에서 처리됩니다. ML Kit가 별도로 처리하는 기기·앱·진단정보에는 Google의 정책이 적용됩니다.

  • ML Kit 개인정보 관련 안내: https://developers.google.com/ml-kit/terms
  • ML Kit Android 데이터 공개 안내: https://developers.google.com/ml-kit/android-data-disclosure

YouTube

집밥노트의 일부 레시피 화면은 YouTube 삽입 플레이어를 사용합니다. 플레이어는 자동재생을 사용하지 않으며 개인정보 보호 강화 모드를 적용합니다. 다만 플레이어를 불러오거나 재생하는 과정에서 Google/YouTube와의 통신 및 정보 처리가 발생할 수 있습니다.

집밥노트의 YouTube 삽입 플레이어는 YouTube API Services를 이용하며, 이용 시 다음 정책이 적용됩니다.

  • YouTube 서비스 약관: https://www.youtube.com/t/terms
  • Google 개인정보처리방침: https://policies.google.com/privacy?hl=ko

GitHub Pages

공지사항은 GitHub Pages에 공개된 공지 파일에서 불러옵니다. 운영자는 공지 요청에 앱에 저장된 레시피·식단·냉장고·Google 계정 정보를 추가하여 전송하지 않습니다.

GitHub의 서비스 이용 과정에서 IP 주소 등 접속정보가 처리될 수 있으며, 자세한 내용은 GitHub의 개인정보처리방침에 따릅니다.

  • GitHub 개인정보처리방침: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement

외부 AI 앱 및 웹서비스

손글씨 사진 간편 입력 또는 유튜브 레시피 간편 정리 기능을 이용하면 이용자의 선택에 따라 Gemini 등 외부 서비스로 이동하거나 사진을 공유할 수 있습니다. 집밥노트는 이용자가 선택한 외부 서비스의 데이터 보관기간, 학습 설정 또는 계정 설정을 통제하지 않습니다. 외부 서비스에서 이루어지는 처리는 해당 서비스의 개인정보처리방침과 이용자 설정에 따릅니다.

5. 국외에서 이루어질 수 있는 정보 처리

Google, GitHub 등 해외 사업자가 제공하는 서비스를 이용하는 과정에서 정보가 대한민국 외 지역의 서버에서 처리될 수 있습니다. Google은 전 세계의 서버에서 정보를 처리할 수 있다고 안내하고 있습니다.

집밥노트에서 이용하는 주요 외부 사업자는 다음과 같습니다.

  • Google LLC: Google 계정 인증, Google Drive, AdMob/UMP, ML Kit, YouTube 및 이용자가 선택하는 Gemini 서비스
  • GitHub, Inc.: GitHub Pages를 통한 공지사항 제공

외부 사업자가 직접 처리하는 정보의 구체적인 저장 위치와 보유기간은 각 사업자의 서비스 및 개인정보처리방침에 따릅니다. 이용자는 선택 기능인 Google Drive 백업, 손글씨 외부 앱 공유, 유튜브 레시피 간편 정리 등을 이용하지 않음으로써 해당 기능에 따른 외부 전송을 하지 않을 수 있습니다. 광고 및 앱에 포함된 외부 SDK의 정보 처리는 별도의 서비스 정책과 이용자 선택 상태에 따라 달라질 수 있습니다.

6. 데이터 삭제 및 이용자의 권리

이용자는 다음과 같은 방법으로 자신의 데이터를 관리할 수 있습니다.

  • 개별 레시피, 식단, 냉장고 항목 및 사용자 태그: 앱의 해당 화면에서 수정 또는 삭제
  • 레시피·식단·냉장고·태그 등 앱 내용 데이터와 초안: 설정의 내부 저장 데이터 초기화
  • Google Drive 백업: Google 계정이 연결된 상태에서 보관 중인 백업본 모두 삭제
  • Google 연결: 앱의 계정 연결 해제 기능 이용
  • 앱에 남은 전체 저장공간·설정·캐시: Android 설정에서 집밥노트의 저장공간 데이터 삭제 또는 앱 제거
  • 문의 이메일에 포함된 개인정보: devnelsupport@gmail.com으로 열람·정정·삭제·처리정지 등을 요청

기기의 데이터를 삭제해도 이전에 생성된 Google Drive 백업본까지 자동으로 삭제되는 것은 아닙니다. Google Drive 백업도 함께 삭제하려면 앱의 백업본 삭제 기능을 별도로 이용해야 합니다.

외부 서비스가 직접 보유하는 정보의 삭제 또는 설정 변경은 해당 서비스가 제공하는 방법을 이용해야 합니다.

7. 개인정보 보호를 위한 조치

운영자는 개인정보 및 이용자 데이터를 보호하기 위해 다음과 같은 조치를 적용합니다.

  • 앱 내용 데이터는 Android 앱 전용 저장공간에 저장
  • 일반 Android 자동 백업 및 기기 전송 대상에서 앱 데이터를 제외하도록 설정
  • 외부 앱으로 사진을 공유할 때 해당 파일에 필요한 읽기 권한만 부여
  • 공지사항 등 네트워크 통신에 HTTPS 사용
  • 문의용 이메일 계정은 운영자 1인만 접근하고 2단계 인증 사용
  • 문의 첨부파일은 처리에 필요한 경우에만 별도 저장하고 보관기간 종료 전 삭제

Google 등 외부 서비스의 전송·저장 보안에는 각 서비스의 보안 정책이 함께 적용됩니다.
